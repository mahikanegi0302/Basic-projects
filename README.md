Basic C++ Projects
A collection of small C++ projects created for hands-on practice and to improve my programming and OOP skills.

1. Expense Tracker
A basic console-based Expense Tracker built in C++ for hands-on practice with Object-Oriented Programming and file handling.

## Features
* Add Expense
* View Expenses
* Search Expense
* Update Expense
* Delete Expense
* Calculate Total Spending
* Monthly Spending Summary
* Category-wise Spending
* Save Expenses to CSV
* Load Existing Expenses
* Open CSV File in the default spreadsheet application
* Input Validation
* Automatic Expense ID Generation

## Concepts Practiced
* C++ OOP
* Classes and Objects
* Encapsulation
* Constructors
* Getters and Setters
* Vectors
* File Handling
* CSV Files
* Input Validation
